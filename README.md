---

**設計原則**

- 所有工具保持「結構化, 清楚的邊界, 容易修改, 可插拔模組」
- 模組獨立, 功能寫壞時只錯單一模組
- 多花一點把結構做對, 誠實顯示錯誤與外部相依
- 絕不 workaround
