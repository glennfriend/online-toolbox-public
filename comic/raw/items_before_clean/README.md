# items_before_clean — 乾淨原圖收件匣(用完即空)

主體 + **乾淨白底**、週圍沒有雜質的配件原圖丟這裡。處理方式=單純去背。

**規則:只要這裡有可轉換的檔案,就全部轉換成去背配件放到 `../items/`,轉換完成後把這裡的原檔刪除。**
正常情況下這裡是空的(只留這個 README)。

- 工具:`[ItemCut]::Cut(原檔, ../items/<id>.png, 232)`(或 `tools/convert-items.ps1`)。
- 命名:WordNet 分類,見 `../../items.md`。
- 白底卡通/線稿用門檻 232;若主體內部的白(白襯衫、白雲)被挖成透明,是去背細縫漏入,
  已由 `ItemCut` 的「侵蝕→保留邊緣連通→膨脹」自動補回(內部白還原成原色不透明)。

配件旁有**雜質(散點、分鏡框、殘字)**的圖不要放這裡,放 `../items_before_noisy/`。
