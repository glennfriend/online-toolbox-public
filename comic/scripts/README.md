# scripts — 版本控管的漫畫劇本

跟你討論後「要存下來」的漫畫 JSON 放這裡,會進 git。編輯器頂列「劇本」下拉即可載入。
(在編輯器裡的小改動不必存這裡 —— 那些即時編進網址 #hash,複製連結就能分享/重現。)

## 命名慣例

- 新漫畫:`YYYY-MM-DD 名稱`(日期在前),例:`2026-07-04 射箭比賽`
- 同一則改新版:在後面加 `v2`、`v3`,例:`2026-07-04 射箭比賽 v2`
  (保留舊版可載入比較;檔名對應加 `-v2`。)

## 新增一則的步驟

1. 建 `scripts/<id>.json`(或 `<id>-v2.json`)放劇本。
2. 在 `scripts/index.json` 加一行 `{ "id", "name", "file" }`。
