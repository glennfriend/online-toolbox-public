# Handbook

自己的**生活資訊手冊**:把查過、學過的生活知識記成問答,之後用**搜尋框或 tag** 秒找。
**支援離線**(主要給手機用:第一次上線開過,之後沒網路也能查)。純前端、零第三方相依。

線上:<https://glennfriend.github.io/online-toolbox-public/handbook/>

## 功能

- **搜尋**:比對問題 + 答案 + tags;空白分隔多個詞 = 同時符合(AND)。
- **tag 快速篩選**:所有 tag 依出現次數列出,點一下篩選、再點取消;可與搜尋同時使用。
- **問答卡**:預設收合(掃問題),點問題展開答案;有搜尋字時符合的卡自動展開。
- **頁面唯讀**:刻意**沒有任何編輯介面**(見下方「管理」)。

## 資料(唯一真相:`data/qa.md`)

一條 = 一個問答,格式:

```
# 問題(一行)
T tag1, tag2
A 答案第一行
答案可以多行,直到下一個「# 」之前都算答案

# 下一個問題
…
```

- `T`:逗號或頓號分隔皆可,可省略。
- `A`:答案可多行、可含空行;忘了寫 `A` 直接寫內容也收(解析器寬容)。
- 內容一律**當純文字顯示**(保留換行),不解析 HTML —— 安全,也不用煩惱跳脫。

## 管理(刻意不做在網頁上)

**`data/qa.md` 本身就是「匯出格式」**——存的格式 = 給人看與校正的格式,所以不需要任何匯出功能:

- **看全部資料 / 某主題的資料** → 請 AI 輸出 `data/qa.md`(全部或篩選過的條目),或直接開檔案。
- **新增 / 校正內容** → 直接改 `data/qa.md`(或請 AI 查證後寫入)→ commit → 部署;
  手機下次上線開啟就會拿到新資料(資料是網路優先,**不需要**動 sw.js 版本)。
- 新增內容時的品質要求:**查證過才寫**(這個工具存在的意義就是「查過一次,以後都信得過」)。

## 離線(2026-08 起支援)

- `sw.js` 預快取 shell(HTML/CSS/JS);**改了 shell 任一檔要把 `VERSION` +1**。
- `data/qa.md` 網路優先、離線退快取 → **資料更新不用動 VERSION**。
- 第一次使用需要網路;離線副本是「每個瀏覽器各自一份」(App 內建瀏覽器開的不算)。

## 結構

```
handbook/
├── index.html      搜尋框 + tag 列 + 問答卡清單
├── styles.css      手機優先(單欄、大觸控目標),深色模式跟隨系統
├── sw.js           service worker(離線)
├── data/
│   └── qa.md       ★ 全部內容(唯一真相;格式見上)
└── js/
    ├── parse.js    qa.md 解析 + 搜尋比對(純函式)
    └── main.js     殼層:載入、搜尋、tag 篩選、渲染
```
