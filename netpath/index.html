開始前, 先看會連到哪裡

首次開頁不連檢測服務. 按 "開始" 才連外, 對方會看到你的 IP. 開始狀態會存在本機, reload 後自動續跑. 按 "暫停" 可關閉續跑

測速會消耗流量, 每次約 2-12 MB. 下載 1 MB, 夠快再下載 10 MB, 上傳 1 MB. 預設開始後每 10 分鐘一次, 首次等滿 10 分鐘

檢測服務與用途 (網域)

    請求不附 Cookie 或 Referer. 內建目標禁止重新導向. 自訂目標會跟隨重新導向, 可能連到清單以外的網域. 資料只留在本機, 不使用 analytics 或第三方 script

    尚無記錄

    每輪每個端點測 3 次, 至少成功 2 次才顯示中位數. 失敗留缺口, 紅點代表該輪有失敗. p95 是 95% 的輪次延遲不超過的數值. 失敗率按請求次數計算

    背景分頁的 timer 可能被拉長到 1 分鐘以上. 休眠, 關頁與慢請求也會減少樣本. 時間軸按實際時間畫, 不補樣本. 測速期間暫停延遲量測, 避免塞滿連線造成誤判

    只留最近 24 小時, 最多 17,280 輪. 預設 4 個目標約 1 MB JSON, localStorage 文字儲存約 2 MB. 加自訂目標會增加用量. 無法儲存時會提示, 仍可量測與匯出

    加入自己的目標

    最多 3 個 HTTPS URL, 存在本機. 使用 no-cors 模式與 redirect: follow. 量到的是含重新導向的總時間, 且只能量總時間. 無法讀內容, 狀態碼或計時細項. 401 / 403 也算有回應, 無法保證服務正常

    自訂目標會跟隨重新導向, 可能連到清單以外的網域

    對方會收到 GET 請求, 請填你允許測試的網址. 大型檔案可能消耗額外流量. URL 也會列入匯出 JSON, 請避免填入機密

    怎麼看出問題在哪裡

    CDN 和所有地區一起變慢
    可能是 WiFi, 分享器, ISP 或其他程式佔滿連線. 先靠近分享器, 再改用網路線比較. 改用網路線後改善, 才更支持 WiFi 有問題
    CDN 忽然飆高或失敗
    WiFi 抖動是常見可能, 也可能是 ISP 或 Cloudflare 異常. 單一曲線無法證明是哪一段, 請一起看台灣與海外是否同步變慢
    附近正常, 海外變慢
    可能是跨國線路, 業者互連或海外服務處理較慢. 比較美西與美東, 或換行動網路再測
    只有一個目標變慢或失敗
    可能是對方伺服器或那條路由. 自訂目標收到錯誤頁也可能顯示很快. 內建端點失敗還可能是 CORS 許可改變
    DNS / TCP / TLS / TTFB 是什麼?
    展開卡片可看細項. DNS 是查位址, TCP 是建立連線, TLS 是加密握手, TTFB 是送出請求到首個回應位元組. 只有允許 Timing-Allow-Origin 的服務可讀. 連線重用時 DNS / TCP / TLS 可能是 0
    為什麼無法確定每一段慢幾 ms?
    瀏覽器量的是到不同服務的 HTTP 請求, 包含排程與服務處理. 無法執行 traceroute 或 ICMP ping. 海外請求也未必經過圖中的台灣機房或 CDN

    區域端點沿用 GCPing. 官方已公告將停用. 失效時會顯示錯誤, 不改用別的區域代替
